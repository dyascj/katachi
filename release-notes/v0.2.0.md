This one makes Katachi feel a lot more like the Figma desktop app, and it's the first release that can update itself.

## Tabs and a home screen

Katachi now opens to a Home screen with your recent files as thumbnails. Search them, start a new design file, or open one. Each file gets its own tab across the top, like Figma. Ctrl Tab cycles through them and Cmd W closes one (you'll get asked first if there are unsaved changes). Files you open from Finder or drop on the window land in new tabs.

## Updates

When a new release is out, an Update now button shows up at the top left of the window. Click it and Katachi downloads the build for your platform, checks it against the signing key compiled into the app, swaps itself out, and restarts. It won't start while anything is unsaved. If you'd rather it never check, set `KATACHI_NO_UPDATE=1`.

This only works going forward, so if you're on 0.1.0, grab 0.2.0 from the assets below once by hand.

## Faster, smaller files

I tested against a real 9,000-layer handoff file.

- Saving went from 255 ms to 20 ms.
- Opening went from 291 ms to 62 ms.
- The file shrank from 32 MB to 7 MB, because Katachi now leaves out every property that's still at its default.
- The autosave that runs every 30 seconds used to freeze the canvas for a quarter second on big files. It runs in the background now.
- Undo keeps far less in memory. Each step used to copy the whole document (about 20 MB on that file); now unchanged layers are shared, so a step costs about 1 MB.

Older files open fine, and files saved by 0.2.0 still open in 0.1.0.

## Things Figma does that Katachi now does too

- Quick actions on Cmd / or Cmd K. Search any command, tool, plugin, or layer name and hit Enter.
- The Frame tool shows Figma's presets (phones, tablets, desktops, slides, watches, paper, social posts).
- Ellipses have arc controls (start, sweep, ratio) for pie slices, donuts, and dial rings.
- Image fills have a Crop mode with zoom and position.
- Instances have a swap picker in their header and in the right-click menu. Components get Add variant, and the property menu offers Variant.
- The Assets panel shows previews of your components, grouped by page.
- Editing a vector shows the selected point's position, plus Bend and Delete.
- Styles named with slashes, like `Brand / Primary`, group into folders.
- Text layers take their text as their name until you rename them, and layer search finds text by what it says.
- Files and pages reopen where you left them.
- Zoom to selection is in the zoom menu, Save As suggests the current name, and you can edit your own comments.

## Bugs fixed

Most of these came out of a long hands-on session designing three small projects in Katachi and writing down everything that felt off.

- Photos disappeared from PNG, SVG, and PDF exports unless they sat at their frame's top-left corner.
- Renaming a layer kept the keyboard trapped in the name field, so shortcuts and typing went to the wrong place.
- The dropdowns inside the effect, prototype interaction, and layout grid editors closed the editor instead of opening. That made background blur and Smart animate unreachable.
- Overrides on an instance got wiped when the main component's layer picked up a style or variable.
- In prototypes, a text label on top of a linked button swallowed the click.
- Closing a pen path selected the frame under it instead of the path.
- The design panel shifted and clipped its controls when a frame had auto layout.
- In multiplayer, layers someone added while you were mid-drag disappeared and were sent to everyone as deletions. A second bug could stop a client from sending changes at all.

Layer rows, pages, tabs, and buttons also have proper names for VoiceOver now.

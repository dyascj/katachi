The first public build of Katachi, a Figma-style design tool written in Rust.

It covers the core of Figma's editor: frames, shapes, pen and text, auto layout, constraints, components with variants and properties, styles, variables with modes, prototyping with Smart animate, multiplayer, comments, Dev Mode, plugins that run Figma's plugin API, and an MCP server so AI agents can read and edit your files. It also opens Figma `.fig` files.

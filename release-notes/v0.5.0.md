The big one in this release: Katachi can now run the AI coding agents you already have, right inside the app, while you watch them design. The rest is a top-to-bottom audit of the app on macOS, Windows, and Linux, with about 80 fixes. Most are things that could lose your work, crash the app, or quietly do the wrong thing.

## Design with your agents, in the app

Press Cmd L (or click the spark at the end of the toolbar) to open the Agent panel. It runs the agents already installed on your computer: Claude Code, Codex, Gemini CLI, OpenCode, or Cursor. They use your own sign-in and models. Katachi has no account or API key of its own, and nothing goes through a Katachi server.

- Ask for a screen, a component, a cleanup, or a dark version, and watch the agent build it on the canvas. Layers it changes glow for a moment, so you can follow along.
- It knows which file, page, and layers you have selected, so "make this a card" works.
- Every change the agent makes can be undone. "Undo these changes" takes back a whole reply in one click.
- Stop ends the agent right away.
- Each tab has its own conversation. Start an agent on one file, switch to another tab, and it keeps working on the file it started on. The tab shows a spinner while it works.
- Follow-up messages continue the same conversation.
- Replies show their formatting: headings, lists, bold, and code.
- If an agent isn't signed in, the panel tells you which command to run, without a wall of error text.

Katachi finds agents installed with npm, Homebrew, or their own installers, even when the app is opened from the Dock or an app menu, which don't get your terminal's PATH. On Windows it handles npm's `.cmd` launchers, and no console windows flash up.

Settings > Agents lists the agents Katachi found. One click adds Katachi to Claude Code, Codex, or Gemini CLI, so you can use it from a terminal too.

## More for agents (MCP)

- New tools: `find_nodes`, `export` (PNG, JPG, WebP, SVG, or PDF, at 2x, 512w, and so on), `get_comments`, and `reply_to_comment`. An agent can now work through your review comments and reply to say what it changed.
- `get_code` writes React components.
- Edits from agents no longer vanish when you happen to be dragging something. They also keep running while you present.
- Only programs on your computer can connect. Web pages, and plugin windows served from your computer, are refused.
- If another copy of Katachi already uses the MCP port, this one picks a free port. Its Agent panel still works on its own files.

## React in Dev Mode

Dev Mode (Shift D) and Copy as code now write React: a component named after the layer, with nested children and either inline styles or Tailwind classes. Vectors come through as inline SVG, and your variable names as CSS variables.

Code fixes that come with it:
- "Fill container" in a vertical stack is now written on the right axis.
- Tailwind gradient classes are real classes now.
- Text is escaped properly in Tailwind and Compose output.
- Variable names that start with an accented or non-Latin letter no longer crash the app.

## Never lose work

- **macOS: Cmd Q asks about unsaved changes.** Quitting from the menu, the Dock, or by logging out used to close Katachi at once, and it also deleted the crash-recovery copies. If you have unsaved work it now asks, tab by tab, like closing the window does.
- After a crash, recovering several files gives each one its own tab. Before, only the last one survived, and Recover could replace the file in the tab you were on.
- Cancelling a quit no longer leaves a stray "Save changes?" on another tab that restarts the quit when you answer it.
- Files opened from a terminal with a short path like `katachi design.katachi` keep their full path, so Recent files and version history work.
- Opening several files at once (from a file manager, or `katachi a.katachi b.katachi`) opens all of them.
- Save As adds `.katachi` if you leave it off, and asks before replacing a file with that name.
- A file that can't be opened says so, with its name, wherever you are.
- On Windows, saving retries for a moment when antivirus or OneDrive briefly holds the file, instead of failing.

## Editing several layers

- Changing one property on several layers now changes only that property. Aligning text across a heading and a caption used to give both the heading's font and size. Changing stroke weight gave every layer the first one's stroke color. Ticking a component property on several instances overwrote their other properties.
- Fields show "Mixed" where the selected layers differ, as in Figma. Fills, strokes, and effects that differ get "Click + to replace them".

## Canvas and export

- Layers with blend modes, blurs, masks, or glass no longer look stretched and shifted when you zoom in on a Retina screen.
- Exports include the whole stroke. Lines and arrows used to export cut in half, and outside strokes were clipped.
- Drop shadows on text and groups now show on the canvas, not just in exports.
- Layers drawn through effects keep their real fonts on the canvas instead of falling back to Inter.
- Frames inside sections work like top-level frames: they get name labels and click-through, prototype connections can reach them, and Present starts on the frame, not the section.
- The Scale tool (K) scales everything inside a frame, not just its strokes and text sizes.
- Resizing a rotated layer keeps its sizing settings, so a rotated Hug frame no longer snaps back.
- Flip horizontal and vertical now flip stars, polygons, arcs, single rounded corners, per-side strokes, and gradient shapes too.
- Boolean operations work with text, so you can knock text out of a shape.
- Undo while editing one text layer can no longer bring back another layer's text.
- Presenting no longer redraws the screen nonstop, which drained laptop batteries.
- Rotating many layers at once and hovering over booleans are much faster.
- Width and height bound to variables now resize vectors and frame contents properly.
- A row that hugs its height no longer collapses when every card in it is set to Fill container. As in Figma, the row switches to a fixed height.

## Panels, components, and libraries

- Putting an instance inside its own main component is refused, as in Figma. It used to keep copying itself until the file became huge.
- Changes to properties of nested instances inside a main component now reach every instance.
- "Go to main component" no longer opens a second tab on a library that's already open.
- Moving or expanding a component in a library file no longer shows up as a library update.
- A library that went missing is found again once it's back, without reopening the file.
- Escape cancels a half-typed value instead of applying it.
- Renaming a style or variable no longer jumps to a different row while you type.
- Undoing a variable delete brings back the layers that used it.
- Deleting a page keeps comments on the right pages.
- Comment threads close on Escape and when you switch pages. Enter sends a reply.
- Gradient "Add stop" selects the stop you just added.
- The pages list scrolls when you have many pages.
- Menus say "Color dodge" and "Hard light" instead of "ColorDodge" and "HardLight".

## Windows

- No more console window behind Katachi. Closing that window used to quit the app, unsaved work and all.
- Katachi starts on a fresh Windows install without the Visual C++ runtime.
- Show in folder selects the file in Explorer.
- The updater runs Windows' own `curl` and `tar`, never a copy sitting next to `katachi.exe` in Downloads.

## Linux and macOS

- If XDG_DATA_HOME is set but empty, Katachi no longer saves its data in whatever folder you started it from.
- The updater no longer offers updates to copies it can't update, like builds run from source or installed in a folder you can't write to, and it cleans up after a failed update. Turning automatic update checks off or on takes effect without a restart.
- With many tabs open, the "+" button stays on screen.
- The README explains how to open the app the first time on macOS, and how to install on Windows.

## Security

- Opening a `.fig` file from someone else can no longer crash Katachi or use up your memory. This covers files built to break the importer.
- A plugin can no longer read files outside its own folder.
- On Linux, plugin windows can't be reached by web pages or other programs.
- SVGs no longer pull in images from files on your disk or network shares.
- Joining a multiplayer session can't crash Katachi, however the host's copy is built.
- Removing someone from a session changes the session code, so they can't just join again.
- Multiplayer connections are more reliable on Windows.

## Under the hood

- The macOS release builds on GitHub's current macOS runner.
- Releases are created as drafts and published only when every file is signed and the notes are in place.
- Clippy runs on every platform in CI, and the codebase is free of warnings.

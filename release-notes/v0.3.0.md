This release is about feel. I had the real Figma desktop app measured (popover sizes, menu colors, how the Settings window is laid out) and rebuilt Katachi's floating UI to match, so your hands and eyes don't have to relearn anything.

## Settings in one place

Cmd , (or Settings on the Home screen) opens a single Settings window with tabs, like Figma's. Your name for comments and multiplayer, theme and glass, canvas preferences, plugins, AI agent setup, updates, and the keyboard shortcut list all live there now instead of in scattered windows and menus.

The canvas preferences are real switches that change behavior:

- Highlight layers on hover
- Show dimensions on objects
- Keep tool selected after use, for drawing a row of shapes without pressing R every time
- Snap to objects
- Nudge amounts for the arrow keys and Shift-arrow

## Popovers, menus, and dialogs

- Everything that floats is solid now. With glass on, only the side panels are see-through. Popovers and menus used to inherit that translucency.
- Fill, stroke, effect, stroke settings, layout guide, font, style, and prototype interaction editors all share Figma's popover. It's 240 points wide with a title, a close button, and the same spacing, and it opens against the left edge of the right panel. Close it with the X, Escape, or a click outside. Escape closes only the popover and leaves your selection alone.
- The color picker is Figma's shape: a saturation and brightness square, thin hue and opacity sliders, then hex and opacity.
- The effect editor is compact, with the type in a dropdown, position, blur, and spread fields, and one color row.
- Adding a stroke or an effect opens its editor right away.
- Menus are near-black in light and dark themes, with a gray hover and a blue check on the current choice. That covers right-click menus, dropdowns, the resizing menu, and the toolbar flyouts, which now open upward and check the tool each group will use.
- The zoom menu has an editable percentage and checks for layout guides, rulers, outlines, and comments.
- The font picker opens with an empty, focused search and a check on the current font.
- The Save changes and crash recovery dialogs dim the canvas and put the main action on the right.
- Toasts are a small dark card above the toolbar.

## The main menu, rearranged

It now reads like Figma's: Back to files and Actions at the top, then File, Edit, View, Object, and Arrange, then Plugins and Preferences, then Help and account. View shows check marks for rulers, outlines, layout guides, and comments. Alt A, H, D, W, V, and S align layers, same as Figma.

## Find, version history, and variables

Find and replace (Cmd F) takes over the left panel instead of floating over the canvas, and Escape closes it. Version history takes over the right panel. Local variables lists collections in a column on the left, next to the selected collection's table. Utility windows open below the tab strip instead of over the window controls.

## Smaller things

- Quick actions has All, Layers, and Plugins tabs and 32-point rows.
- Layer rows are a little taller, and the dark theme's selected-layer color matches Figma's.
- Shortcut symbols like Option and Control no longer show up as empty boxes.
- Variable bindings say "Stroke width" instead of `StrokeWidth`.
- Dropdowns inside editors were nearly invisible in the light theme. They're readable now.
